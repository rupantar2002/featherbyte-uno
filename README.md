# Featherbyte Uno

An Uno-shaped RISC-V board. Arduino Uno form factor, powered by the WCH CH32V203C8T6 MCU. Open source hardware.

## Overview

Featherbyte Uno drops a RISC-V microcontroller into the familiar Arduino Uno footprint, so it works with existing Uno shields, cases, and mounting holes — while giving you a modern, cheap, feature-packed core underneath.

## Key features

- **MCU:** WCH CH32V203C8T6 (RISC-V, QingKe V4B core)
- **Form factor:** Arduino Uno R3 compatible pinout and dimensions
- **Cost:** designed to be a low-cost, open alternative to classic AVR-based Uno boards
- **Open hardware:** schematics, PCB layout, and BOM included
